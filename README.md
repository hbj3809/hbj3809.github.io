# 황병준 포트폴리오 (정적 웹사이트)

빌드 없이 그대로 서비스하는 HTML/CSS/JS 입니다.

- 로컬 확인: `python -m http.server 8765 --bind 127.0.0.1` 후 http://127.0.0.1:8765
- 게시: GitHub Pages — Settings → Pages → Deploy from a branch → `main` / `/ (root)`
- 페이지: `index.html`(홈) · `about.html`(소개) · `experience.html`(경력) · `projects.html`(프로젝트) · `projects/*.html`(상세 사례) · `ai.html`(AI로 일하는 방식) · `skills.html`(기술)
- 공용 스타일·스크립트: `assets/css/site.css`, `assets/js/site.js`
- 글꼴: Pretendard(jsDelivr CDN). 연결이 안 되면 시스템 한글 글꼴로 대체됩니다.

이 저장소는 공개용입니다. 회사 내부 정보·고객사 실명·개인 연락처(이메일 제외)는 넣지 않습니다.
