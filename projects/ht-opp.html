개요비대면 시험 감독을 돕는 실시간 영상과 자동 탐지

코로나19 팬데믹으로 비대면 시험 수요가 급증하던 시기에 휴먼텍소프트 솔루션사업부에서 온라인 부정시험방지 솔루션 HT-OPP 를 맡았습니다.

핵심은 두 가지입니다. 하나는 응시자의 웹캠 영상을 감독관에게 실시간으로 보여 주는 것이고, 다른 하나는 부정행위로 볼 수 있는 상태를 모델이 자동으로 잡아 감독관과 응시자에게 바로 알리는 것입니다.

기획·개발·QA·납품의 전 주기를 혼자 수행했고(기여도 100%), 솔루션을 상용화해 교육기관에 납품했습니다.

  • 기간: 2020.06 ~ 2021.09
  • 역할: PM 및 전 범위 개발(기여도 100%)
  • 대상: 교육기관의 비대면 시험
  • 결과: 상용화 완료, 교육기관 납품, 탐지 정확도 100%(교육기관 피드백 기준, 적발 건수 지표 없음)

아키텍처영상 경로와 탐지 · 알림 경로 초안

응시자 브라우저의 웹캠 영상은 WebRTC P2P 다중 연결로 감독관 화면에 전달됩니다. 같은 영상은 탐지 모델(OpenCV · TensorFlow)에도 들어갑니다. 시야 이탈이나 자리 이탈이 5초 이상 이어지면 Socket.IO 로 감독관과 응시자에게 알립니다.

  • 영상 전달(P2P)과 탐지 · 알림 경로를 나눠 구성
  • 알림은 감독관과 응시자 양쪽으로 보냄
  • 서버는 Java · Spring, 데이터는 MariaDB · PostgreSQL

이 부분은 근거 자료가 적어 기술 스택과 당시 환경을 바탕으로 쓴 초안입니다. 게시 전에 사실과 다른 곳이 없는지 확인해 주세요.

기술을 고른 이유와 판정 규칙을 정한 이유입니다.

오픈소스 위에서 시작

비대면 시험 수요가 갑자기 늘었습니다. 그래서 영상 통신을 처음부터 만들지 않고, WebRTC 오픈소스를 시험 감독용 다중 연결 구조로 커스터마이징했습니다.

영상은 P2P 로 직접

응시자 영상을 서버에 모으지 않고 감독관 브라우저로 바로 보냅니다. 서버가 영상을 중계하지 않으므로 지연과 서버 부담이 줄어듭니다.

탐지 대상은 행동이 분명한 두 가지

시야 이탈(정면을 보지 않음)과 자리 이탈(일어나거나 화각을 벗어남)에 집중했습니다. 행동이 분명해 딥러닝으로 판정하기 어렵지 않은 조건이었습니다. 그 결과 납품 기관 피드백 기준 정확도 100%를 받았습니다.

순간 동작이 아니라 지속 시간으로 판정

고개를 잠깐 돌리는 순간까지 알리면 감독관도 응시자도 알림에 지칩니다. 그래서 이탈 상태가 5초 이상 이어질 때만 알림을 보냈습니다.

판단은 감독관이, 교정은 응시자가

알림을 감독관 화면과 응시자 화면에 함께 보냅니다. 응시자는 바로 자세를 고칠 수 있고, 부정행위 처리 여부는 감독관이 판단합니다.

주요 기능과 구현

기능은 실시간 영상 감독과 자동 탐지 · 알림, 두 가지로 나뉩니다.

  • 실시간 영상 감독: WebRTC 오픈소스를 커스터마이징한 P2P 다중 연결(Multi-connection) 기반 실시간 영상 감독 시스템
  • 부정행위 자동 탐지: OpenCV · TensorFlow 기반 시야 이탈(정면 응시가 아닐 때) · 자리 이탈(자리에서 일어나거나 화각을 벗어날 때) 2개 조건 탐지 모델

  • 실시간 알림: Socket.IO 로 감독관 · 응시자에게 알림 UI · 자동 메시지 전송
  • 전 주기 단독 수행: 기획 → 개발 → QA → 납품

CASE 01 · AI 탐지

탐지 대상을 행동이 분명한 두 조건에 집중하기

1문제 상황

코로나19 팬데믹으로 비대면 시험 수요가 급증했습니다. 교육기관이 온라인으로 시험을 치르려면 감독관이 원격 응시자의 부정행위를 실시간으로 확인할 수단이 필요했습니다.

2원인 분석

무엇을 부정행위 신호로 보느냐가 탐지 정확도를 좌우합니다. 정면을 보지 않는 시야 이탈과 자리에서 일어나거나 화각을 벗어나는 자리 이탈은 행동이 분명했습니다. 그래서 딥러닝으로 판정하기 어렵지 않은 조건이었습니다.

3해결 과정
  1. WebRTC 오픈소스를 커스터마이징한 P2P 다중 연결로 응시자 영상을 감독관에게 실시간 전달
  2. OpenCV · TensorFlow 기반으로 시야 이탈(정면 응시가 아닐 때) · 자리 이탈(자리에서 일어나거나 화각을 벗어날 때) 2개 조건 탐지 모델 구현

  4. 기획 · 개발 · QA · 납품 전 주기 단독 수행 후 교육기관 납품

CASE 02 · 실시간 알림

순간 동작은 거르고 지속된 이탈만 알리기 초안

1문제 상황

탐지 모델은 프레임마다 결과를 냅니다. 응시자가 잠깐 고개를 돌리거나 자세를 고칠 때마다 알리면 감독관 화면에 알림이 쌓입니다. 응시자도 시험에 집중하기 어렵습니다.

2원인 분석

프레임 단위 판정 결과를 그대로 알림으로 바꾸면 짧은 동작과 실제 이탈을 구분할 수 없습니다.

3해결 과정
  1. 이탈 상태가 이어진 시간을 누적하고, 5초 안에 정상으로 돌아오면 초기화
  2. 5초 이상 이어질 때만 부정행위 의심 이벤트 발행
  3. Socket.IO 로 감독관에게는 알림 UI, 응시자에게는 자동 경고 메시지를 동시에 전달
  4. 최종 부정행위 처리 판단은 감독관이 맡도록 역할 분리
4결과

두 조건 · 5초 지속 판정과 감독관 · 응시자 동시 알림을 갖춘 상태로 상용화하고 교육기관에 납품했습니다.

CASE 03 · 실시간 영상

감독관 한 명이 여러 응시자를 실시간으로 보기: WebRTC 다중 연결 초안

1문제 상황

비대면 시험에서는 감독관 한 명이 여러 응시자의 웹캠 영상을 동시에 봐야 합니다. 수요가 급하게 늘어 영상 통신을 처음부터 만들 시간이 없었습니다.

2원인 분석

WebRTC 오픈소스의 기본 형태는 일대일 영상 연결 중심입니다. 감독관 한 명에게 여러 응시자의 영상을 모아야 하는 시험 감독에는 그대로 쓸 수 없었습니다.

3해결 과정
  1. WebRTC 오픈소스를 커스터마이징해 감독관과 응시자 사이 P2P 다중 연결(Multi-connection) 구성
  2. 시그널링으로 연결 정보를 교환한 뒤 영상은 P2P 로 직접 전달
  3. 감독관 화면에 여러 응시자 영상을 모아 보는 실시간 감독 화면 구성
4결과

실시간 영상 감독 시스템을 상용화하고 교육기관에 납품했습니다.
