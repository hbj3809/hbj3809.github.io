무엇을, 왜 만들었나

코로나19 팬데믹으로 비대면 시험 수요가 급증하던 시기에 온라인 부정시험방지 솔루션을 기획부터 납품까지 혼자 맡아 상용화했습니다. 응시자 웹캠 영상을 감독관에게 실시간으로 보여 주고, 응시자 영상 프레임을 서버로 보내 직접 학습한 모델이 시야 이탈·자리 이탈을 자동으로 잡아 알립니다. 교육기관 납품 시험에서는 한 시험에 응시자 100명 내외를 동시에 감독했고, 납품한 교육기관의 피드백 기준 탐지 정확도는 100%입니다(실제 적발 건수 지표는 받지 못함).

개요비대면 시험 감독을 돕는 실시간 영상과 자동 탐지

코로나19 팬데믹으로 비대면 시험 수요가 급증하던 시기에 휴먼텍소프트 솔루션사업부에서 온라인 부정시험방지 솔루션 HT-OPP 를 맡았습니다.

핵심은 두 가지입니다. 하나는 응시자의 웹캠 영상을 감독관에게 실시간으로 보여 주는 것이고, 다른 하나는 부정행위로 볼 수 있는 상태를 모델이 자동으로 잡아 감독관과 응시자에게 바로 알리는 것입니다.

탐지 모델은 가져다 쓰지 않고 직접 학습했습니다. 시험장 환경과 응시자 환경을 직접 구성하고, 다양한 각도·자세·동작 데이터를 추가해 학습했습니다. 판정은 응시자 영상 프레임을 서버로 보내 서버에서 합니다.

기획·개발·QA·납품의 전 주기를 혼자 수행했고(기여도 100%), 솔루션을 상용화해 교육기관에 납품했습니다. 교육기관 납품 시험에서는 한 시험에 응시자 100명 내외를 동시에 감독했습니다.

  • 기간: 2020.06 ~ 2021.09
  • 역할: PM 및 전 범위 개발(기여도 100%)
  • 대상: 교육기관의 비대면 시험
  • 규모: 한 시험에 응시자 100명 내외 동시 감독(교육기관 납품 시험 기준, 측정값이 아닌 운영 규모)
  • 탐지 모델: 시험장·응시자 환경을 직접 구성하고 다양한 각도·자세·동작 데이터를 추가해 직접 학습, 서버에서 판정
  • 결과: 상용화 완료, 교육기관 납품, 탐지 정확도 100%(교육기관 피드백 기준, 적발 건수 지표 없음)

아키텍처영상 경로와 탐지 · 알림 경로

응시자 웹캠 영상은 두 경로로 갑니다. 감독용 영상은 WebRTC P2P 다중 연결로 감독관 화면에 실시간 전달됩니다. 판정용 영상 프레임은 서버로 보내지고, 서버의 탐지 모델(직접 학습, OpenCV · TensorFlow)이 시야 이탈 · 자리 이탈을 판정합니다. 이탈이 5초 이상 이어지면 Socket.IO 로 감독관과 응시자에게 알립니다.

  • 감독용 영상(P2P)과 판정용 영상 프레임(서버)의 경로를 나눠 구성
  • 탐지 · 판정은 서버에서 실행하고, 알림은 감독관과 응시자 양쪽으로 보냄
  • 서버 애플리케이션은 Java · Spring, 데이터는 MariaDB · PostgreSQL

핵심 흐름시험 세션 한 번

감독관이 시험실을 열고 응시자가 들어오면 감독관과 응시자 사이에 WebRTC P2P 영상 연결이 맺어집니다. 시험이 끝날 때까지 응시자 영상 프레임이 서버로 가고, 서버에서 탐지 → 판정 → 알림이 반복됩니다.

판정 규칙응시자 감시 상태 전이 초안

판정 기준은 순간 동작이 아니라 지속 시간입니다. 시야 이탈이나 자리 이탈이 감지돼도 바로 알리지 않습니다. 그 상태가 5초 이상 이어질 때만 감독관과 응시자에게 알립니다.

개념 데이터 모델 초안

실제 테이블 구조가 아니라 시험 감독 업무를 이루는 개념을 정리한 모델입니다. 시험실 단위로 감독관과 응시자가 묶이고, 응시마다 탐지 이벤트와 알림이 쌓입니다.

이 부분은 근거 자료가 적어 기술 스택과 당시 환경을 바탕으로 쓴 초안입니다. 게시 전에 사실과 다른 곳이 없는지 확인해 주세요.

설계 결정왜 이렇게 만들었나 초안

기술을 고른 이유와 판정 규칙을 정한 이유입니다.

영상 통신은 오픈소스 위에서 시작

비대면 시험 수요가 갑자기 늘었습니다. 그래서 영상 통신을 처음부터 만들지 않고, WebRTC 오픈소스를 시험 감독용 다중 연결 구조로 커스터마이징했습니다. 탐지 모델은 이와 달리 직접 학습했습니다.

감독 영상은 P2P, 판정은 서버에서

감독관이 보는 영상은 서버가 중계하지 않고 WebRTC P2P 로 감독관 브라우저에 바로 보냅니다. 부정행위 판정은 응시자 영상 프레임을 서버로 보내 서버의 탐지 모델이 맡습니다. 보는 경로와 판정하는 경로를 나눈 구조입니다.

탐지 모델은 가져오지 않고 직접 학습

시험장 환경과 응시자 환경을 직접 구성하고, 다양한 각도 · 자세 · 동작 데이터를 추가해 모델을 학습했습니다. 응시자마다 조명과 카메라 각도가 달라, 실제 응시 화면에 가까운 데이터가 필요했습니다.

탐지 대상은 행동이 분명한 두 가지

시야 이탈(정면을 보지 않음)과 자리 이탈(일어나거나 화각을 벗어남)에 집중했습니다. 행동 자체는 분명해 딥러닝으로 판정하기 어렵지 않은 조건이었습니다. 다만 조명 · 카메라 각도에 따른 오탐이 있어 학습 데이터를 보강해 대응했고, 납품한 교육기관 피드백 기준 정확도 100%를 받았습니다.

순간 동작이 아니라 지속 시간으로 판정

고개를 잠깐 돌리는 순간까지 알리면 감독관도 응시자도 알림에 지칩니다. 그래서 이탈 상태가 5초 이상 이어질 때만 알림을 보냈습니다.

판단은 감독관이, 교정은 응시자가

알림을 감독관 화면과 응시자 화면에 함께 보냅니다. 응시자는 바로 자세를 고칠 수 있고, 부정행위 처리 여부는 감독관이 판단합니다.

이 부분은 근거 자료가 적어 기술 스택과 당시 환경을 바탕으로 쓴 초안입니다. 게시 전에 사실과 다른 곳이 없는지 확인해 주세요.

주요 기능과 구현

기능은 실시간 영상 감독과 자동 탐지 · 알림, 두 가지로 나뉩니다.

  • 실시간 영상 감독: WebRTC 오픈소스를 커스터마이징한 P2P 다중 연결(Multi-connection) 기반 실시간 영상 감독 시스템
  • 부정행위 자동 탐지: 응시자 영상 프레임을 서버로 보내 판정하는 OpenCV · TensorFlow 기반 시야 이탈(정면 응시가 아닐 때) · 자리 이탈(자리에서 일어나거나 화각을 벗어날 때) 2개 조건 탐지 모델

  • 지속 시간 판정: 두 조건 중 하나라도 5초 이상 이어질 때만 부정행위 의심으로 판정
  • 실시간 알림: Socket.IO 로 감독관 · 응시자에게 알림 UI · 자동 메시지 전송
  • 전 주기 단독 수행: 기획 → 개발 → QA → 납품

1문제 상황

코로나19 팬데믹으로 비대면 시험 수요가 급증했습니다. 교육기관이 온라인으로 시험을 치르려면 감독관이 원격 응시자의 부정행위를 실시간으로 확인할 수단이 필요했습니다.

2원인 분석

무엇을 부정행위 신호로 보느냐가 탐지 정확도를 좌우합니다. 정면을 보지 않는 시야 이탈과 자리에서 일어나거나 화각을 벗어나는 자리 이탈은 행동이 분명했습니다. 그래서 딥러닝으로 판정하기 어렵지 않은 조건이었습니다.

3해결 과정
  1. WebRTC 오픈소스를 커스터마이징한 P2P 다중 연결로 응시자 영상을 감독관에게 실시간 전달
  2. OpenCV · TensorFlow 기반 시야 이탈(정면 응시가 아닐 때) · 자리 이탈(자리에서 일어나거나 화각을 벗어날 때) 2개 조건 탐지 모델을 직접 학습하고, 응시자 영상 프레임을 서버로 보내 판정
  3. 두 조건 중 하나라도 5초 이상 이어지면 Socket.IO 로 감독관 · 응시자에게 알림 UI · 자동 메시지 전송
  4. 기획 · 개발 · QA · 납품 전 주기 단독 수행 후 교육기관 납품
4결과

솔루션을 상용화해 교육기관에 납품했습니다. 납품한 교육기관의 피드백 기준 탐지 정확도는 100%였습니다(실제 적발 건수 지표는 받지 못함).

탐지 흐름(개념): 서버에서 행동이 분명한 두 조건을 지속 시간으로 판정

배운 점

행동이 분명한 조건을 탐지 대상으로 고른 것이 정확도를 지킨 출발점이었습니다.

CASE 02 · AI 탐지

조명 · 카메라 각도가 만든 오탐 → 각도 · 자세 · 동작 데이터를 더해 직접 학습

1문제 상황

응시자마다 조명과 웹캠 각도가 달랐습니다. 이 때문에 정상적으로 응시하는 모습을 시야 이탈이나 자리 이탈로 잘못 탐지하는 경우(오탐)가 실제로 생겼습니다. 오탐이 그대로 알림이 되면 감독관은 알림을 믿기 어렵고, 응시자는 시험에 집중하기 어렵습니다.

2원인 분석

조명이나 카메라 각도가 바뀌면 같은 자세도 모델에게는 다르게 보입니다. 학습 데이터가 실제 응시 환경의 다양한 각도 · 자세를 충분히 담지 못하면 정상 응시를 이탈로 잘못 판정할 수 있습니다.

3해결 과정
  1. 시험장 환경과 응시자 환경을 직접 구성해 실제 응시 화면에 가까운 조건을 마련
  2. 다양한 각도 · 자세 · 동작 데이터를 추가해 탐지 모델을 직접 학습(공개 모델을 가져다 쓰지 않음)
  3. 순간 판정 결과를 바로 알리지 않고, 이탈 상태가 5초 이상 이어질 때만 알림으로 이어지게 해 짧은 오판정이 곧바로 알림이 되지 않게 함
4결과

다양한 데이터로 직접 학습한 모델과 5초 지속 판정을 갖춰 상용화하고 교육기관에 납품했습니다. 납품한 교육기관의 피드백 기준 탐지 정확도는 100%였습니다(실제 적발 건수 지표는 받지 못함).

CASE 03 · 실시간 영상

응시자 네트워크 끊김 · 지연: 감독 화면과 서버 판정이 함께 흔들리는 문제

1문제 상황

응시자는 각자 다른 장소에서 자기 네트워크로 시험에 접속합니다. 실제 운영에서 응시자마다 네트워크 품질이 달라 끊김과 지연이 생겼습니다. 영상 프레임이 늦게 오거나 빠지면 감독관 화면의 영상이 멈추거나 늦어지고, 서버가 판정에 쓸 프레임도 늦거나 비게 됩니다.

2원인 분석

네트워크 품질은 응시자 쪽 환경이라 서버가 통제할 수 없습니다. 감독용 영상은 응시자에서 감독관으로 P2P 로 가고 판정용 프레임은 응시자에서 서버로 가기 때문에, 응시자 네트워크가 흔들리면 감독 화면과 서버 판정이 함께 영향을 받습니다.

3해결 과정
  1. 응시자 네트워크 품질이 고르지 않다는 것을 전제로, 감독용 영상(P2P)과 판정용 프레임 전송(서버) 두 경로에 미치는 영향을 나눠 살핌
  2. 끊김 · 지연이 생겨도 시험 감독과 판정이 이어지도록 영상 연결과 프레임 전송 방식을 보완
4결과

응시자마다 네트워크 품질이 다른 환경에서 실시간 감독과 서버 판정을 운영하는 솔루션으로 상용화하고, 한 시험에 응시자 100명 내외 규모로 교육기관에 납품했습니다.
